## Objetivo

Diseñar e implementar en `crates/e101-map` el modelo de datos de territorios (localizaciones, provincias y grafo de adyacencias) con verificación de invariantes topológicos.

## Interfaz o contrato

- Tipos base:
  ```rust
  #[derive(Copy, Clone, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
  pub struct LocationId(pub u32);

  #[derive(Copy, Clone, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
  pub struct ProvinceId(pub u16);

  #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
  pub enum AdjacencyType {
      Land,
      CoastalSea,
      DeepSea,
      River,
      Strait,
  }
  ```
- Estructura `TerritoryModel` / `MapTopology`:
  - Mapeo `LocationId -> ProvinceId` (cada localización pertenece a exactamente una provincia).
  - Tabla de provincias con centroide (coordenadas enteras/fijas), área en km², tipo de terreno y lista de localizaciones miembros.
  - Grafo o lista plana contigua de adyacencias indexada por `ProvinceId` con tipo de conexión.
- Métodos de consulta:
  - `neighbors(province: ProvinceId) -> &[NeighborEntry]`
  - `are_adjacent(a: ProvinceId, b: ProvinceId) -> bool`

## Criterios de aceptación

- [ ] Modelo de memoria compacto en tablas contiguas indexadas por ID sin dispersión ni punteros circulares.
- [ ] Invariante de simetría en adyacencias terrestres: si la provincia A es vecina terrestre de B, B es necesariamente vecina de A con el mismo tipo de conexión.
- [ ] Invariante de pertenencia: no existen localizaciones sin provincia asignada ni provincias sin localizaciones.
- [ ] Cero aritmética de punto flotante en la lógica persistente del modelo.

## Pruebas requeridas

- [ ] Carga de un dataset de mapa de prueba (ej. 20 provincias y 100 localizaciones) validando todas las consultas espaciales.
- [ ] Pruebas de propiedad con `proptest` comprobando la simetría y reciprocidad de todas las conexiones terrestres.

## Fuera de alcance

- Algoritmos avanzados de cálculo de rutas navales o comerciales (Fase 2).
- Carga de imágenes o generación de mallas poligonales GPU.
