## Objetivo

Implementar en `crates/e101-sim` el subsistema inicial de soberanía y control efectivo sobre provincias, verificando la preservación de invariantes bajo 10.000 cambios aleatorios de frontera.

## Rol

role:sim

## Interfaz o contrato

- Estado de soberanía y control en tablas SoA:
  - `sovereign: Vec<EntityId>` (soberano legal de cada provincia).
  - `effective_controller: Vec<EntityId>` (actor que ejerce el control militar/administrativo de facto).
  - `control_ratio: Vec<Ratio>` (grado de control efectivo, de 0.0 a 1.0, representado en punto fijo `Ratio`).
- Órdenes o mutaciones admitidas:
  - `TransferSovereignty { province: ProvinceId, new_sovereign: EntityId }`
  - `SetEffectiveControl { province: ProvinceId, controller: EntityId, ratio: Ratio }`
- Invariantes no negociables:
  1. Cada provincia tiene siempre un soberano asignado válido (nunca nulo ni entidad inexistente).
  2. El controlador efectivo debe ser una entidad existente.
  3. `0 <= control_ratio <= 1.0` (escala 0 a 1_000_000).

## Criterios de aceptación

- [ ] Las transferencias de territorio emiten deltas conformes al sistema `apply.rs`.
- [ ] No se producen provincias sin soberano bajo ninguna secuencia de transferencias.
- [ ] Prueba de estrés de 10.000 mutaciones de frontera y control ejecutadas aleatoriamente sin romper ningún invariante.
- [ ] Todo cálculo numérico se efectúa con tipos de punto fijo (`Ratio`), sin flotantes.

## Pruebas requeridas

- [ ] Prueba de estrés con generador determinista (`e101-rng`): 10.000 transferencias de soberanía y control concurrentes o secuenciales, validando la integridad del estado tras cada tick.
- [ ] Prueba unitaria de rechazo de transferencia a una entidad eliminada o inválida.

## Fuera de alcance

- Grupos de interés (estratos), legitimidad de gobierno, revueltas armadas o parlamentos (Fase 3).
