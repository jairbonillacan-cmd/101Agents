## Objetivo

Implementar en `crates/e101-store` el modelo de almacenamiento SoA (Structure of Arrays) con identificadores estables y slotmaps generacionales para entidades de ciclo de vida dinámico.

## Rol

role:engine

- Sección del documento maestro: §21 (Principios de ingeniería - Datos orientados a memoria), §22 (Stack - e101-store), §23 (Determinismo), Anexo P (Fase 1 · Núcleo), Anexo AF (Semana 3), Anexo AG (`store.md`)
- ADR relacionados: ADR 0001, ADR 0002
- Tareas relacionadas: #T-104, #T-108, #T-109

## Archivos permitidos

- `crates/e101-store/**`

## Interfaz o contrato

- Tipos de identificación:
  ```rust
  #[derive(Copy, Clone, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
  pub struct EntityId(pub u32);
  ```
- Tablas SoA para entidades estáticas/densas (provincias, localizaciones) indexadas directamente por ID contiguo con acceso por columnas vectoriales independientes.
- Colecciones `SlotMap` generacionales (usando `slotmap` de Cargo o implementación interna canónica) para entidades dinámicas (ejércitos, personajes, tratados) compuestas por `(index: u32, generation: u32)`.
- Separación de accesos: lectura inmutable compartida (`&State`) con iteradores paralelos compatibles con `Rayon`, y mutación restringida a la fase de aplicación.

## Criterios de aceptación

- [ ] Inserción, borrado y consulta por ID en tiempo O(1).
- [ ] La reutilización de ranuras previene referencias obsoletas gracias a la comprobación de la generación del ID (eliminando el problema ABA).
- [ ] La iteración de componentes se realiza siempre en orden determinista canónico de IDs (sin colecciones aleatorias no ordenadas).
- [ ] Lectura concurrente de múltiples columnas en paralelo mediante hilos de trabajo sin bloqueos ni contención.

## Pruebas requeridas

- [ ] Pruebas unitarias de inserción, eliminación y validación de generación al reutilizar índices.
- [ ] Prueba de lectura concurrente multihilo con `rayon` sobre 100.000 entidades.

## Fuera de alcance

- Lógica de sistemas de simulación o cálculo de deltas (Fase 2).
- Serialización a disco de partidas guardadas (cubierto en T-112).
