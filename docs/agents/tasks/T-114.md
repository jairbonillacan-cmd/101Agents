## Objetivo

Implementar en `crates/e101-content` el analizador y validador de definiciones de entidades históricas desde archivos RON con informes detallados de errores de validación.

## Rol

role:data

## Contexto

- Sección del documento maestro: §05 (Especificación detallada de entidades), §20 (Formato de datos), §22 (Stack - RON y validadores), Anexo P (Fase 1 · Núcleo), Anexo AG (`content-format.md`)
- ADR relacionados: ADR 0001
- Tareas relacionadas: #T-010, #T-105, #T-113

## Archivos permitidos

- `crates/e101-content/**`
- `games/epoch/data/entities/**`

## Interfaz o contrato

- Esquema RON de definición de entidad:
  ```rust
  #[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
  pub struct EntityRawDef {
      pub tag: String,
      pub name_key: String,
      pub color_rgb: (u8, u8, u8),
      pub capital_province: u16,
      pub primary_culture: String,
      pub state_religion: String,
      pub government_type: String,
  }
  ```
- Validador `ContentValidator`:
  - `pub fn load_and_validate_entities(dir: &Path, map: &MapTopology) -> Result<Vec<EntityRawDef>, Vec<ValidationError>>`
- `ValidationError`:
  - Estructura con ruta de archivo, número de línea, columna y mensaje explicativo del problema semántico detectado.

## Criterios de aceptación

- [ ] Carga y deserializa archivos `.ron` de entidades individuales o colecciones en `games/epoch/data/entities/`.
- [ ] Valida unicidad estricta de tags (ej. no pueden coexistir dos entidades con tag `BYZ`).
- [ ] Valida integridad referencial: la capital referenciada debe existir en la topología del mapa (`ProvinceId` válido).
- [ ] En caso de error sintáctico o semántico, emite mensajes legibles indicando con exactitud el archivo y la línea del fallo.

## Pruebas requeridas

- [ ] Pruebas unitarias cargando un lote de definiciones válidas de entidades de 1300.
- [ ] Pruebas de rechazo con archivos de prueba corruptos (tag repetido, provincia inexistente, color RGB fuera de rango) verificando la presencia de los mensajes de error correspondientes.

## Fuera de alcance

- Compilación binaria a base de datos de contenido empaquetada (Fase 2).
- Definición de bienes económicos o tecnologías en RON (Fase 2 y 4).

## Estimación

3 a 5 horas de agente.
