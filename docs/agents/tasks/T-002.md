## Objetivo

Configurar el workspace raíz de Cargo con `rust-toolchain.toml`, lints compartidos de determinismo y `deny.toml` para licencias y seguridad.

## Rol

role:infra

## Contexto

- Sección del documento maestro: §22 (Stack tecnológico recomendado), §40 (Workspace de referencia), §46 (Reglas de código para agentes), Anexo P (Fase 0 · Preproducción), Anexo AF (Semana 1)
- ADR relacionados: ADR 0001, ADR 0002
- Tareas relacionadas: #T-001, #T-003, #T-004

## Archivos permitidos

- `Cargo.toml`
- `Cargo.lock`
- `rust-toolchain.toml`
- `deny.toml`
- `rustfmt.toml`
- `.cargo/config.toml`

## Interfaz o contrato

- `Cargo.toml`:
  ```toml
  [workspace]
  resolver = "3"
  members = ["crates/*", "tools/xtask"]

  [workspace.package]
  edition = "2024"
  license = "LicenseRef-101-Agents-Games-Proprietary"

  [workspace.lints.clippy]
  float_arithmetic = "deny"
  unwrap_used = "warn"
  ```
- `rust-toolchain.toml`: Fijar una versión específica de Rust estable con los componentes `rustfmt` y `clippy`.
- `deny.toml`: Configuración estricta de `cargo-deny` autorizando licencias compatibles (MIT, Apache-2.0, BSD-3-Clause) y vetando avisos de vulnerabilidades (`advisories`).
- `[workspace.dependencies]`: Declaración centralizada con versiones fijas de dependencias compartidas (`serde`, `ron`, `thiserror`, `proptest`, `rayon`, `blake3`, `postcard`, `zstd`, `rand_core`, `indexmap`, `slotmap`).

## Criterios de aceptación

- [ ] `Cargo.toml` raíz configurado con edición 2024, resolver "3" y glob `crates/*`.
- [ ] Lints de clippy en workspace prohíben `float_arithmetic` a nivel global.
- [ ] `rust-toolchain.toml` fija canal y versión reproducible.
- [ ] `deny.toml` operativo para control de licencias comerciales y avisos de seguridad.
- [ ] `cargo check` y `cargo build` terminan en verde sin advertencias.

## Pruebas requeridas

- [ ] `cargo check --workspace` retorna código 0.
- [ ] `cargo deny check` finaliza exitosamente con las dependencias base declaradas.
