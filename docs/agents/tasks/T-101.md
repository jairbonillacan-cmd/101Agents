## Objetivo

Implementar el crate `crates/e101-time` con la estructura de día absoluto `Day` y las conversiones deterministas bidireccionales con los calendarios juliano y gregoriano.

## Interfaz o contrato

- Tipo fundamental: `Day(pub u32)` representando el número de días transcurridos desde una época base fija (ej. 1 de enero de 1300 = 0 o época astronómica juliana).
- Enum de calendarios:
  ```rust
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
  pub enum Calendar {
      Julian,
      Gregorian,
  }
  ```
- Conversiones:
  - `Day::from_ymd(cal: Calendar, year: i32, month: u8, day: u8) -> Result<Day, DateError>`
  - `day.to_ymd(cal: Calendar) -> (i32, u8, u8)`
- Implementaciones de `Copy`, `Clone`, `PartialEq`, `Eq`, `PartialOrd`, `Ord`, `Hash`, `Serialize`, `Deserialize`, `Display`.
- Sin dependencias de `std::time::SystemTime` ni aritmética de coma flotante.

## Criterios de aceptación

- [ ] Crate `e101-time` compila sin errores ni advertencias bajo las reglas de determinismo.
- [ ] Conversión exacta de ida y vuelta (`Day -> YMD -> Day`) para cualquier día válido entre los años 1300 y 2060.
- [ ] Soporte correcto de bisiestos julianos (múltiplos de 4) y gregorianos (múltiplos de 4, excepto centenarios no divisibles por 400).
- [ ] Fechas históricas de referencia verificadas (1 de enero de 1300, 15 de octubre de 1582, 1 de enero de 2060).

## Pruebas requeridas

- [ ] Pruebas de propiedad (`proptest`) verificando la biyección completa entre `Day` y fecha para un millón de días aleatorios.
- [ ] Pruebas unitarias de casos de borde (finales de febrero, años bisiestos julianos vs gregorianos).
