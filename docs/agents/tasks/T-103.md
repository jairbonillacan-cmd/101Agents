## Objetivo

Implementar el crate `crates/e101-rng` con un generador de números pseudoaleatorios determinista basado en contador, indexado por semilla, sistema, entidad y día.

## Rol

role:engine

## Archivos permitidos

- `crates/e101-rng/**`

## Interfaz o contrato

- Función o constructor principal:
  ```rust
  pub fn rng(seed: u64, system: u16, entity: u32, day: u32) -> RngStream;
  ```
- `RngStream` implementa `rand_core::RngCore` (o API determinista propia sin estado mutable compartido entre hilos).
- Métodos auxiliares:
  - `pub fn next_u32(&mut self) -> u32`
  - `pub fn next_u64(&mut self) -> u64`
  - `pub fn gen_range_u32(&mut self, min: u32, max: u32) -> u32`
  - `pub fn gen_bool_ratio(&mut self, numerator: u32, denominator: u32) -> bool`
- Algoritmo subyacente: generador basado en contador determinista (Philox, ChaCha o función hash BLAKE3/splitmix).

## Criterios de aceptación

- [ ] Cero dependencias del sistema operativo o reloj para generación de entropía en simulación.
- [ ] Orden independiente: invocar `rng(seed, system, entity, day)` produce exactamente la misma secuencia numérica sin importar el orden en que los hilos concurrentes ejecuten la llamada.
- [ ] Pasa pruebas estadísticas elementales de uniformidad de distribución de bits e independencia de secuencias contiguas.

## Pruebas requeridas

- [ ] Prueba de concurrencia: llamar a `rng` en 16 hilos en orden aleatorio y comprobar que cada combinación de `(seed, system, entity, day)` obtiene valores idénticos a la ejecución secuencial.
- [ ] Prueba estadística básica (prueba chi-cuadrado para distribución uniforme de 100.000 muestras).
