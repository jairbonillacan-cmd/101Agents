## Interfaz o contrato

- Formato estandarizado según `docs/adr/0000-template.md`.
- Definición de determinismo: `Mismo binario + mismos datos + misma semilla + mismos comandos => mismo estado bit a bit en cada tick`.
- Lista exhaustiva de prohibiciones en los crates del núcleo:
  1. Tipos de punto flotante (`f32`, `f64`) en estado persistente y contabilidad.
  2. Iteración no ordenada de `std::collections::HashMap` o `HashSet`.
  3. Consultas al reloj de sistema (`SystemTime`, `Instant`), variables de entorno, sistema de archivos no hermético o red.
  4. Aleatoriedad global no controlada; obligatoriedad de `e101-rng::rng(seed, system, entity, day)`.
  5. `unsafe` sin un ADR específico aprobado.
- Estrategia de paralelismo: lectura paralela que produce deltas y fase de aplicación ordenada con clave canónica.
